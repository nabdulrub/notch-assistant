# Security

Notch Assistant listens to a microphone and can approve commands for a coding
agent, so reports about either are taken seriously.

## Reporting a problem

Please report it privately: on this repository, open the Security tab and choose
"Report a vulnerability". Do not open a public issue.

Say what you found, how to make it happen, and which version you were on. You
will get an answer, and credit in the fix if you want it.

## What counts

- Audio leaving the Mac while the assistant is asleep
- A command being approved without the user saying or clicking yes
- Anything that lets another process on the Mac, or a web page, drive the assistant
- A key being written anywhere other than the app's own folder
